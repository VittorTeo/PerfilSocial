# 🌐 Meu Perfil Social

Um projeto simples e elegante feito para centralizar as minhas principais redes sociais e formas de contato em um só lugar.

---

## 👨‍💻 Sobre o Projeto

O **Meu Perfil Social** é uma página web desenvolvida para reunir meus links profissionais e sociais, facilitando a conexão com recrutadores, outros estudantes e profissionais da área da tecnologia.

No momento, você pode me encontrar através dos seguintes links no projeto:
* 🐙 **GitHub**
* 💼 **LinkedIn**
* 📸 **Instagram**

---

## 🛠️ Tecnologias Utilizadas

Para o desenvolvimento deste projeto, utilizei as seguintes tecnologias/linguagens:

* **HTML5:** Estruturação de marcação do conteúdo da página.
* **CSS3:** Estilização, layout e design responsivo básicos.
